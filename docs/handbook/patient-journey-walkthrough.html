THE PATIENT JOURNEY
02 / 11
Start to finish

Every step, in order

A patient can enter this journey from the website or straight from WhatsApp, and can drop into "manage my appointment" from either one at any point. Every automatic WhatsApp message below is covered in detail on the pages that follow.

Patient books an appointment Websiteor WhatsApp
Picks an open day and a real 15-minute slot on the /book page, or does the same thing by chatting with RC directly on the website or on WhatsApp, no form at all. Slots are checked against the live schedule, so two patients can never take the same one.
Booking confirmed WhatsApp, automatic
The moment a booking is saved, a confirmation template lands on the patient's WhatsApp with their name, day and time, and token number. No staff step.
Reminder before the visit WhatsApp, automatic
A scheduled job sends a reminder template with a tappable "View your appointment" button that opens the patient's own booking directly, phone number already filled in.
Patient visits, pays the consultation fee Website
From the My Appointment page the patient taps Pay Now, which opens a secure Razorpay payment link for the exact fee. Once paid, a payment received template confirms it on WhatsApp.
Plans change: reschedule or cancel Websiteor WhatsApp
On the website, changing someone else's appointment requires proving the phone number is really theirs, a one-time code sent over WhatsApp. On WhatsApp itself, the sender's own number already is that proof, so no code is needed there.
Staff can notify the whole queue Admin dashboard
Running late, or closing early? The front desk sends a clinic notice template to everyone booked in today, straight from the admin dashboard, in one tap.
Bringing a past patient back Admin dashboard
For a patient who has visited before but never messaged the clinic on WhatsApp, staff can send a one-tap welcome template with a direct booking link and a call button.

RC ASSISTANT · VIEW & RESCHEDULE
04 / 11
Self-service, in chat

Ask RC to find or move an appointment

Alongside booking, timings, fees and location, RC looks up a patient's own appointment and walks them through moving it, on the website chat and on WhatsApp, using the same day-and-time picker as booking.

RC's greeting includes "View my appointment" and "Reschedule" alongside booking and availability.

How it works

  • View my appointment: patient gives their phone number, RC lists every active booking on it, no gate, since this is a read-only lookup, same as opening the My Appointment page.
  • Reschedule: RC reuses the same day and time picker booking uses. On the website, moving someone's appointment first requires the phone-ownership check described on the next page. On WhatsApp, the sender's own number is proof enough.
  • Both work in English, Telugu and Hindi, same as the rest of RC.
Nothing extra to learnReschedule uses the exact same day-and-time picker a patient already sees when booking, so there's no separate flow to figure out.

STEP 5 · SECURITY BEFORE CHANGING A BOOKING
05 / 11
Anti-fraud gate

Proving it's really your number

A phone number by itself is not a secret, it can be read off a prescription, a bill, or a forwarded message. So before the website lets anyone cancel, reschedule or pay for a booking, it sends a one-time code to that number over WhatsApp and asks for it back.

What the patient sees

A six-digit code arrives on WhatsApp within seconds. Typing it into the website unlocks cancel, reschedule and pay for that number, for a short window, so a patient handling more than one action doesn't get a fresh code every time.

  • Expires in 10 minutes, single use, five guesses before it's locked
  • Only requested when someone tries to change a booking, never for a simple lookup
  • WhatsApp itself skips this step entirely, since only the phone's real owner can message from it
